# 可执行计划：线关系引导的有界平面支撑精修

日期：2026-10-23。状态：已完成P0/P1首轮核查、P2四场景小拟合和P3三组各200步的首轮开发试验；尚未完成独立测试或项目目标。
本任务承接主问题“共面接近不等于结构归属”。不覆盖旧实验，不将旧开发集收益当作独立测试结论。

## 目标与范围

研究假设：相对于普通局部RGB+mask精修，平面对条件化的交线关系及其学习到的有限作用范围，能在固定几何上进一步减少边界外溢，并控制误改。

固定XYZ、点数、相机估计和已有候选平面参数；仅更新支撑标签。初版不新增平面、不处理未分配点、不删除点、不做几何吸附、不微调DUSt3R、不同时引入跨视图网络。原未分配点仍进入适用的完整评价，不能借此隐藏错误。

“加入线”本身不是原创性主张。必须对照PlaneTR和Learning Pairwise Inter-Plane Relations（ECCV 2020）的接触线/分割精修机制，明确新增机制，而非只对比Plane-DUSt3R。

## P0：冻结问题、近邻差异与数据口径

操作：
1. 复核学习平面GT、render_layout_plane_ids、共同域指标之间的语义：可见表面还是遮挡消除布局；家具、门窗、无效标签的处理写清。
2. 枚举实际可用的RGB、点图、候选、变换与训练清单；逐级检查场景/建筑分组、上游和边界网络的训练交集。
3. 对PlaneTR与ECCV 2020平面对关系论文列出输入、预测对象、线来源、接触范围、优化变量和监督的对照表；只实现有限范围门控不能未经比较就称为新机制。
4. 固定原5px欧氏边界协议；补充对称Boundary IoU，预先规定分辨率和带宽。总体实例匹配与固定映射的归属错误分开报告。
5. 复用已有oracle和误差分析，确认当前版本候选覆盖、合并/拆分、边界与内部错误；固定匹配下的缺失身份不直接等于缺失物理平面。

输出：protocol.json、data_manifest.json、nearest_work_comparison.md、baseline_diagnosis.json及少量诊断图，均写入新输出目录。
通过条件：输入/GT语义明确、变换可核对、划分可说明。若缺少独立数据，明确提出缓存或边界模型重训需求，不能把旧DEV换名为TEST。

## P1：复现与最小数据适配

1. 在旧199/190缓存上复核已保存指标；如需要重跑使用新目录。查清差异后再训练。
2. 建立预测输入与监督分离的patch数据接口；部署输入不读取GT标签、GT位姿或GT决定的ROI。历史GT目录中保存的预处理元数据应单独导出并审计来源。
3. 初始用64x64原点图区域、补充上下文，RGB按显式变换从原图采样。具体尺寸视映射和显存小试验冻结，不把插值放大当作新增细节。
4. 各组使用同一批轴对齐patch，中心来自预测mask边界/竞争区域并混入普通区域，不按GT错误挑选；无交线组不能隐式使用交线方向裁剪。交线坐标先作为附加通道，旋转裁剪若尝试需另做消融。
5. 候选集合相同，支持多候选及保留原标签；对不在局部候选中的真实目标显式标记，完整评价不排除。重叠patch汇总logit再统一决策，不顺序覆盖。

测试：像素往返映射、点序与XYZ不变、无效区域、候选顺序、线符号、无交线/无候选、重叠patch融合。
输出：schema版本化patch索引、8–12张输入/目标对齐图及测试结果。

## P2：普通局部精修基线（先验证可学习性）

架构建议：小型空间编码器读取RGB上下文，共享候选分支读取预测mask及几何残差，输出局部候选logit；不继续只拼接几个标量给旧MLP。
初始损失：归属CE+0.5实例Dice；正确点保护权重先固定为旧设置2。权重是待验证初值，非最优配置。
监督使用训练场景的实际预测与固定训练匹配，GT只作目标；有效实例、空mask和缺失候选处理必须写入协议。

先用已有4训练场景做拟合与显存诊断，不宣称泛化；必须能显著降低训练错误，并确认新增参数收到梯度。若不能，先查输入/监督/实现，不扩数据。
通过后建议20–40训练场景、8–12个独立开发场景的小规模对照；数量以P0实际数据清查为准。先短跑测单步耗时/峰值显存，再固定所有组相同训练预算；不承诺未经测量的训练时长。

## P3：同预算三组核心实验

| 组 | 内容 | 所回答的问题 |
| --- | --- | --- |
| M0 | 当前finite模型，作为参考 | 相对原主线是否进步 |
| M1 | RGB+预测mask+几何残差的局部精修，交线通道置零 | 普通空间精修基线 |
| M2 | M1+交线坐标/侧向关系，固定作用权重 | 直接使用线是否有效 |
| M3 | M2+学习的沿线/局部有效作用权重 | 学习适用范围是否有独立价值 |

M1/M2/M3保持相同patch、候选、上游预测、优化器、批次序列、训练步数和尽量匹配的网络容量；不同处明示。M2使用冻结的固定权重，M3替换为学习权重，不同时换主干/采样/loss。

学习作用权重必须实际控制候选竞争中的线关系贡献，而不是只输出一张未参与推理的热图。第一版以最终归属损失学习，显式有效范围监督作为以后单独实验，不一开始增加多个辅助头。

核心可证伪条件：M3须优于M1与M2，而不仅优于M0；若M1有效但M3无增量，不能声称线是主要贡献。

输出：同域指标表、逐场景改正/误改统计、正常/失败案例、作用权重与实际修改区域对应图。

## P4：针对一个已证实问题做至多两轮修改

只在M3已有价值或清楚诊断出一个可修复瓶颈时继续。优先候选是错误先验训练：适量交线偏移、旋转及错误平面对，GT归属不变；与正常训练保持同预算比较。
单独报告正常先验和扰动先验性能，避免以忽略所有线换取表面鲁棒性。扰动幅度由训练/开发预测误差分布确定，不能依据最终测试选择。
若两轮后无可重复线增量，停止该分支并报告，不自动换一批loss继续扫参。候选瓶颈若占主导，申请调整任务而不是默默新增平面模块。

## P5：冻结测试与基线比较

在开发阶段决定最终配置和预算。建议预留至少30个未用于调参的场景；需P0确认可用，不能以帧级随机切分替代。若上游边界网络见过这些场景，必须另选场景或重新训练相关上游后再称独立。
关键组跑3个随机种子；按场景统计均值、中位数、退化比例，报告场景级置信区间。开发有效后才进入最终测试，不用测试集选模型或阈值。

比较原分配、最近面、普通RANSAC、M1/M2/M3与Plane-DUSt3R。对PlaneTR/平面对关系近邻决定复现原法还是同输入机制适配：适配结果明确标注，不称完整原论文复现。PLANA3R可后续扩展，不阻塞首轮。

暂定阶段验收：相对精修前边界错误下降>=20%；改正/误改>=3；>=80%场景总归属不退化；总体错误降低，实例F1与支撑IoU不出现明确系统性下降。还须有M3相对M1/M2的可重复增量。这些门槛不是公认学术标准，也不是发表保证。

所有图统一相机、XYZ、点序、采样及实例配色，显示原始/普通精修/完整方法/GT和改正-误改；不能只选最漂亮的一例。
